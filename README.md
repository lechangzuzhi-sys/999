# 使用方法（适合完全不懂代码的人）

下面这套方法可以帮你把这个项目跑起来，步骤很简单，照着做就行。

## 1. 先注册并登录 GitHub

- 进入 GitHub 官网注册一个账号。
- 注册成功后登录你的账号。

## 2. 把这个仓库复制到你的 GitHub 里

- 登录后，点击右上角的加号按钮。
- 选择 Import repository。
- 在 Your old repository's clone URL 这里，粘贴楼主给你的 Gitee 链接。
- 在 Repository name 这里，随便起一个名字，比如：momo-share。
- 最后点绿色按钮 Confirm / Continue 保存。

## 3. 打开自动运行权限

- 进入你刚刚导入的仓库页面。
- 点击 Settings。
- 左侧找到 Actions。
- 找到 Actions permissions 这一项。
- 选择第一个选项，然后点下面的 Save。
- 如果还不行，可以再看看其他相关设置，把权限调开。

## 4. 把你的分享链接填进去

- 回到仓库主页。
- 点击文件 MMSLS.js。
- 打开后，把你的分享链接填进去。
- 你可以这样填：
  - 三个冒号之间都填一个内容，或者
  - 删除两个冒号只留一个，直接填链接
- 只要能让程序读到你的链接就行。

## 5. 手动运行一次

- 点击上方的 Actions。
- 左侧找到 click分享link。
- 右边点 Run workflow。
- 稍等一下，系统就会开始运行。

## 6. 之后怎么做

- 大约每 30 多分钟会执行一次。
- 你每天最好换一次分享链接，然后重复第 4 步和第 5 步。
